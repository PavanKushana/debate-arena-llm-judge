# Prototype (judge v0): Team Logic Debate Scoring API

My first version of the logic-track judge (May 2026), built before the final judge in [`../judge_service_v2/`](../judge_service_v2/). It is kept here to show how the design evolved.

A REST API and UI for scoring debate transcripts, detecting rebuttals, and determining winners using LLM-based argument extraction and semantic similarity scoring.

## Run it locally

**You need:** Python 3.11+ and [Ollama](https://ollama.com) (free, runs models on your own computer).

```bash
ollama pull llama3.2
cd prototype
pip install fastapi uvicorn ollama requests pydantic sentence-transformers scikit-learn transformers torch streamlit
python -m uvicorn main:app --reload        # API on http://localhost:8000 (docs at /docs)
python -m streamlit run app.py             # UI on http://localhost:8501 (in a second terminal)
```

Settings (environment variables):

| Variable | Default | Purpose |
|---|---|---|
| `OLLAMA_HOST` | `http://localhost:11434` | Where Ollama runs |
| `OLLAMA_MODEL` | `llama3.2` | Model used for extraction and scoring |
| `ES_API` | `http://localhost:8000` | Optional reference-argument search API; if it isn't reachable, reference arguments are generated by the LLM |

## API Endpoints

### `GET /`
Health check.

**Response:**
```json
{"message": "Team Logic API is running!"}
```

---

### `POST /score`
Score a single team's debate transcript.

**Request:**
```json
{
  "topic": "Should universities offer free education",
  "speaker": "Team A",
  "transcript": "Free education reduces inequality. Student debt is destroying young people's futures.",
  "reference_arguments": []
}
```

| Field | Required | Description |
|-------|----------|-------------|
| `topic` | yes | Debate topic |
| `speaker` | yes | Team or speaker name |
| `transcript` | yes | What the speaker said |
| `reference_arguments` | no | Custom references. If empty, fetched from Elasticsearch or auto-generated |

**Response:**
```json
{
  "speaker": "Team A",
  "topic": "Should universities offer free education",
  "reference_source": "elasticsearch",
  "ollama_scoring": {
    "coverage": 1.0,
    "quality": 0.8,
    "final_score": 0.8
  },
  "huggingface_scoring": {
    "coverage": 1.0,
    "quality": 0.87,
    "final_score": 0.87,
    "scoring_details": {
      "model": "TF-IDF + all-mpnet-base-v2"
    }
  }
}
```

---

### `POST /winner`
Determine winner from any number of team scorecards.

**Request:**
```json
{
  "teams": [
    {"speaker": "Team A", "final_score": 0.8},
    {"speaker": "Team B", "final_score": 0.65},
    {"speaker": "Team C", "final_score": 0.2}
  ]
}
```

**Response:**
```json
{
  "overall_winner": "Team A",
  "vote_count": {"Team A": 3, "Team B": 1},
  "strategies": {
    "coverage_based": {"winner": "Team A", "reasoning": "..."},
    "quality_weighted": {"winner": "Team A", "reasoning": "..."},
    "composite": {"winner": "Team A", "reasoning": "..."},
    "final_score": {"winner": "Team A", "reasoning": "..."}
  }
}
```

**Winner Strategies:**

| Strategy | Formula | Description |
|----------|---------|-------------|
| `coverage_based` | max(coverage) | Team that addressed most reference arguments |
| `quality_weighted` | max(quality) | Team with highest average argument quality |
| `composite` | 0.5 x coverage + 0.5 x quality | Balanced combination |
| `final_score` | coverage x quality | Multiplicative formula |

---

### `POST /debate`
Full pipeline in one call — scores all teams and determines winner.

**Request:**
```json
{
  "topic": "Should universities offer free education",
  "teams": [
    {
      "speaker": "Team A",
      "transcript": "Free education reduces inequality and gives everyone equal opportunity."
    },
    {
      "speaker": "Team B",
      "transcript": "Universities need funding. Free education reduces teaching quality."
    }
  ],
  "reference_arguments": []
}
```

**Response includes:**
- `references_used` — reference arguments used for scoring
- `scorecards` — per-team scores with Ollama and HuggingFace results
- `rebuttals` — detected rebuttals and undercuts between teams
- `winner` — winner determined by multiple strategies
- `llm_assessment` — holistic AI verdict of the debate

---

## Scoring Formula

```
final_score = coverage x quality

coverage = matched_arguments / total_extracted_arguments
quality  = average similarity score of matched arguments
```

An argument is matched when similarity score is greater than or equal to 0.4.

---

## Scoring Methods

| Method | Model | How it works |
|--------|-------|-------------|
| Ollama | llama3.2 | LLM rates similarity 0.0-1.0 as a judge |
| HuggingFace | TF-IDF + all-mpnet-base-v2 | TF-IDF (30%) + semantic embeddings (70%) |

---

## Reference Arguments Priority

When no reference_arguments are provided:

```
1. Reference-argument search API (ES_API) — real Change-My-View debate corpus
   if unavailable or no exact match:
2. Similarity search on Elasticsearch
   if Elasticsearch unreachable:
3. Auto-generated by LLM (llama3.2)
```

## Using the Streamlit UI

1. Open `http://localhost:8501`
2. Enter debate topic
3. Enter Speaker 1 and Speaker 2 names
4. Add arguments one by one for each speaker
5. Click Evaluate Debate
6. View results in tabs:
   - Speaker 1 tab — scorecard with extracted arguments
   - Speaker 2 tab — scorecard with extracted arguments
   - Comparison and Winner tab — winner, strategies, rebuttals, AI assessment
   - Ollama vs HuggingFace tab — side by side model comparison

## Troubleshooting

| Problem | Solution |
|---------|---------|
| ConnectionError: Failed to connect to Ollama | Start Ollama (`ollama serve`) or set `OLLAMA_HOST` |
| reference_source shows llm_generated | Expected without a reference-argument API (`ES_API`); the LLM generates references instead |
| Streamlit shows 0 scores | Make sure FastAPI is running on port 8000 |
| HuggingFace model slow first time | Model downloads on first run (~400MB), subsequent runs are fast |
